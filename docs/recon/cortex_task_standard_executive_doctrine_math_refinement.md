## Standard

Cortex should provide runtime executive capacity rather than external task
rules. Task-standard formation is the task-set front half of that loop: the
model forms a visible task-local standard, Cortex preserves it across lifecycle
events, compares claims and evidence against it, gates closure when the relation
does not hold, and updates session state from visible mismatch or relief.

The biology analogy is a delivery-layer analogy only. It maps executive
capacities into Cortex state and gates; it is not biological equivalence and
does not claim model consciousness.
