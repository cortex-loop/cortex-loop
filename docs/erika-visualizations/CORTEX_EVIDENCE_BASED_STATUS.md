## 6. Mechanism map

This is the biology-facing tracker in the document.
If the question is "what have we actually stolen from the brain so far?", start here.

### Working analogy for Core

Core is closer to a modulation/constraint layer than a "brainstem" analogy.
That analogy is useful only if it stays subordinate to the packet:

- Core constrains and certifies.
- SRE owns active control.
- AUX stays support-only and removable.

The analogy is helpful for thinking.
It is not permission to move weighted executive policy into Core.
